# Чарли — готовый проект для сборки Android APK через GitHub Actions

Это обновлённый пакет именно для текущей версии **Charlie** с русским интерфейсом.
Внутри находится `main.py`, полученный из `charlie_fixed_android_ru.py`.

## Что исправлено

- старый ZIP проверен;
- `main.py` синхронизирован с рабочей русской версией Charlie;
- камера и микрофон объявлены как Android runtime permissions;
- сборка выполняется не в Termux/Pydroid, а на Ubuntu GitHub Actions;
- Java 17 используется для Android-сборки;
- Buildozer 1.6.0;
- Cython 3.0.12, совместимый с текущей stable-веткой python-for-android;
- python-for-android закреплён на стабильном релизе `v2026.05.09` (commit `58d21141`);
- Android API 35 + NDK 28c;
- только `arm64-v8a`, чтобы уменьшить время и размер сборки;
- workflow сам проверяет синтаксис `main.py` и наличие APK;
- готовый APK публикуется как Artifact **Charlie-APK**.

## Как получить APK с телефона

1. Создайте новый репозиторий на GitHub, например `Charlie-Android`.
2. Загрузите **содержимое этого каталога**, а не сам ZIP внутри ZIP:
   - `main.py`
   - `buildozer.spec`
   - `build.sh`
   - `README.md`
   - `.github/workflows/build-apk.yml`
3. Сделайте Commit.
4. Откройте **Actions**.
5. Выберите **Build Charlie APK**.
6. Нажмите **Run workflow**.
7. Дождитесь окончания сборки.
8. Откройте завершённый запуск и найдите **Artifacts → Charlie-APK**.
9. Скачайте APK и установите его на телефон.

После установки это будет отдельное приложение **Чарли**, а не Pydroid 3.
При первом запуске/нажатии «СТАРТ» Android сможет выдать приложению разрешения на **камеру и микрофон**, потому что они объявлены непосредственно в APK.

## Важная деталь

Charlie сохраняет развивающуюся память в `charlie_brain.json` во внутреннем хранилище приложения. Встроенных русских слов, вопросов и готовых фраз в этой версии нет: начальная вокальная система содержит только примитивные звуки.

## Если GitHub Actions покажет ошибку

Не запускайте сборку снова много раз. Откройте failed run → шаг **Build debug APK** и пришлите последние строки лога. В этом пакете workflow уже делает предварительную проверку, поэтому ошибка будет локализована значительно точнее.
